# ADR-081：阅读位置与钉住的句子只存本机

用户读长篇电子书（例如 Standard Ebooks 把整本书放在一个页面里，也提供按章节分页的版本）时，经常不记得上次读到哪。整句翻译和点击查词时，用户手指着的那句话就是他正在读的地方，ENX 天然知道。

我们决定：**扩展把每本书「最近一次被查词、翻译或钉住的那句话」记为这本书的阅读位置，另外允许用户钉住任意多句；两者只存在本机 `chrome.storage.local`，按登录的用户分开，不发给 enx-api，也不弹授权提示。** 下次打开这本书的任意一页，页角提示「从上次的位置继续」，点一下跳回那句话。

跨设备同步要把句子原文存到服务端，越过 adr-032 的「不存正文」边界，留给 #855 单独决定（默认关闭，打开时告知并取得同意，可能是付费功能）。

## Decision

### 1. 一切触发都先落到「句子」，再成为阅读锚点

| 触发 | 得到的句子 |
| ---- | ---- |
| 点击查词（含查词浮层） | 被点的词所在的句子 |
| 短语查询 | 选区所在的句子 |
| 划词整句翻译、悬停整句翻译 | 发去翻译的那句 |
| 在侧边栏整句卡上点「钉住」 | 这张卡的句子 |

单词到句子的扩展**复用现有分句逻辑** `WordProcessor.extractSentenceContext`（`Intl.Segmenter`），不另写一套，保证同一个位置从不同入口得到同一句话。在侧边栏里点词不算，那不是在读正文。

句子再变成**阅读锚点**：

- 句子原文（空白规整后）；
- 句子前、后各 32 个字符，只用于在页面里找回这句话，不展示给用户；
- 句子在正文文本里的字符偏移和正文总长度，用于消歧和兜底；
- 所在页面的地址（规范化规则同 adr-032，去掉 fragment、凭据、跟踪参数）和页面标题；
- 记录时间。

所有界面（页角提示、侧边栏）都只显示句子原文，不管它来自查词还是翻译。

### 2. 阅读位置：每本书一个，最近一次为准

每本书只有一个阅读位置，任一触发都覆盖它。**不做「只前进不后退」**：按章节分页时不同页面的偏移无法比较，重读时也会卡在旧位置。用户回头查前面的词，位置就退回去，这是有意的：用户点到哪，就是读到哪。

查词频繁，写入防抖 2 秒，标签页隐藏或卸载时立即写。

### 3. 钉住的句子：每本书可多条，也更新阅读位置

钉住一句话会在这本书下保存一个阅读锚点，直到用户取消钉住，之后的查词不会覆盖它。钉住同时是一次触发，更新阅读位置。同一本书最多 100 条，满了不自动删除，提示用户先取消一些。

### 4. 书标识

阅读位置按**书**存，不按页面存，因为按章节分页的书，每章地址不同。

- 默认：规范化后的页面地址就是书标识，一页一本书。
- 站点适配器可以给出更宽的书标识。新增可选字段 `bookKey(location)`。第一个是 Standard Ebooks：取 `/ebooks/<作者>/<书名>`，整页版 `…/text/single-page` 与各章节 `…/text/<章节>` 归为同一本书。其他电子书网站以后按需加适配器。

### 5. 打开页面时的提示与跳转

ENX 在某页启用学习模式后，如果这本书有阅读位置，页角显示一个小提示，显示那句话的开头。用户点它、关掉它，或在这页产生新的阅读锚点后，提示消失。

点提示：

1. 锚点在当前页面：在正文里找回句子，滚到视口中部，用 Highlight API 闪烁高亮一次，同时打开这个标签页的侧边栏（adr-050）。
2. 锚点在同一本书的另一页（例如上次读到第 5 章，这次打开第 2 章）：提示写明是哪一页，点击后跳到那个地址，到达后自动执行第 1 步。待跳转的锚点按标签页存在 `chrome.storage.session`。

**找回规则**：在正文文本里精确匹配句子原文；有多处时，按前后文吻合程度、再按与记录偏移的距离挑一处；一处也没有时，按偏移占正文长度的比例滚到附近，并明确提示「没找到原句」，不假装定位成功。找回逻辑是 `src/lib/` 里的纯函数，输入是正文文本和锚点，输出是位置或失败原因，不接触 DOM。

### 6. 侧边栏

侧边栏顶部显示这本书的阅读位置（句子原文 + 跳转图标），下面列出这本书钉住的句子，每条都可以跳转和取消钉住。整句卡上加「钉住」按钮。全部书的列表不在侧边栏里做，见 #856（本机）和 #855（同步）。

### 7. 存储与淘汰

- 只在 `chrome.storage.local`，**按 Clerk 用户 ID 分开存**（与 `savedPagesStore.ts` 的 `savedPages:<userId>` 同一做法）：同一浏览器里换一个 ENX 账号，看不到前一个账号的阅读位置和钉住的句子。
- 未登录时不记录、不显示提示。登出不删除，数据留在本机但不显示；同一账号再登录后恢复。
- 每个用户最多保留 200 本书，按「最近打开或写入」淘汰最久没碰的一本，**连同它钉住的句子一起删**。
- 句子原文、页面地址不进诊断日志、Sentry 或统计上报。

## Considered Options

- **存到服务端，首次钉住时弹窗征求同意**：最先的提议。跨设备是将来的需求，眼下桌面单浏览器就够用；存句子原文要修订 adr-032 和隐私条款，还有一个用户迟早会忘的授权弹窗。否决，移到 #855 作为可选功能。
- **只有手动钉住，没有自动位置**：用户的问题本身就是「忘了」，忘了读到哪的人也会忘了钉。否决，自动记录为主，钉住为辅。
- **阅读位置只前进不后退**（参照 `readingProgress.ts` 的水位）：理由见 Decision 2。否决。
- **用浏览器的 Text Fragment（`#:~:text=`）跳转**：只能精确匹配，无法用前后文和偏移消歧，失败时也没有兜底与提示，高亮样式不受控。否决，统一用自己的找回逻辑；跨页面时只用它到达目标地址，不用它定位。
- **按滚动比例记位置**：换字号、换窗口宽度、网站改版都会偏，也无法跨整页版与章节版。只作为找不到原句时的兜底。

## Consequences

- 隐私条款不用改：「哪篇文章被读过，只有你自己的浏览器知道」仍然成立。将来可以加一句说明扩展在本机记住阅读位置。
- 换电脑、换浏览器配置文件、清除扩展数据都会丢失阅读位置，在 #855 之前这是已知限制。
- 按用户分开是界面上的隔离，不是加密：数据仍以明文留在这台机器的扩展存储里，能打开扩展开发者工具的人看得到。与 `savedPagesStore` 相同的取舍。公共电脑上的保护（加密或登出时清除）见 #859。
- 注销账号（adr-062）删不到各浏览器里的本机副本；它们不再显示，因为那个用户 ID 不会再登录。随扩展卸载或清除扩展数据消失。
