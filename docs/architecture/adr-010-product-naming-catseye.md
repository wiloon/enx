# ADR-010：产品命名 — 猫眼翻译 / Catseye

| 字段 | 值 |
| --- | --- |
| **状态** | Accepted — 2026-08-25 |
| **日期** | 2026-08-25 |

---

## Context

enx 目前是内部开发代号，产品准备上线前需要确定正式的中文名和英文名。

已知竞品：
- **沉浸式翻译**（Immersive Translate）——整页替换式翻译
- **ReadLang**——以生词本/语言学习为主的阅读工具

命名约束：
1. 中文名需包含"翻译"二字
2. 灵感来自天上的星星，呼应公司品牌"星钺"（Starlabrys，"星星 + 希腊神话双刃斧 labrys"）已有的星空/神话意象
3. 希望能融入作者自己养的猫"皮皮"这个个人元素

## Options Considered

| 候选（中文 / 英文） | 意象来源 | 未采用原因 |
| --- | --- | --- |
| 译境翻译 / Contexto | "语境"抽象概念，不依赖星/猫意象 | 与"星星"这条主线无关联，仅作为不依赖主题的保底候选保留 |
| 织女翻译 / Vega | 织女星，牛郎织女传说，"织"呼应"编织语言" | 隐喻贴切，但与"猫"的个人化诉求无关联；Vega 在可视化工具圈（Vega-Lite）已有同名产品 |
| 天狼翻译 / Sirius | 天狼星，全天最亮恒星 | Sirius 因 SiriusXM 品牌强势，商标/域名压力大 |
| 启明翻译 / Daystar | 启明星（金星），"引路的光" | 英文对应词辨识度低；直译 Lucifer 有负面联想 |
| 猫爪翻译 / Catspaw | 猫爪星云（Cat's Paw Nebula），真实存在的星云 | 同样满足星+猫的双重意象，偏可爱/交互动效风格，作为备选保留（例如可用于点击翻译的爪印动效彩蛋） |
| 皮皮翻译 / Pipi | 作者的猫"皮皮"直接命名 | 中文里"皮皮"已被大量无关产品/角色使用（皮皮虾、皮皮鲁等），辨识度低、不够独特 |
| **猫眼翻译 / Catseye（采用）** | 猫眼星云（Cat's Eye Nebula, NGC 6543），真实存在的星云 | — |

## Decision

采用 **猫眼翻译 / Catseye**。

## Rationale

- **天文关联**：真实存在"猫眼星云"（Cat's Eye Nebula, NGC 6543），与母品牌"星钺"的星空意象一脉相承，不是另起一套无关的比喻。
- **语义关联**："猫眼"在中文里本身是常用词（门上的猫眼、猫眼石），引申义是"看得清楚、看透"，贴合翻译产品"帮你看懂另一种语言"的定位。
- **个人化**：呼应作者养的猫"皮皮"，"猫眼"可以直接用皮皮的眼睛作为品牌视觉/吉祥物素材来源，比"皮皮翻译"这种直白命名更有品牌延展空间。
- **差异化核实**：通过 WebSearch 检索（2026-08-25），未发现现有翻译类产品、浏览器插件或 App 使用"猫眼翻译"或"Catseye"作为品牌名。需注意的是"猫语翻译"系列宠物语言翻译 App（把猫叫声"翻译"成人话）字形、读音接近，未来在应用商店/搜索场景可能造成一定关键词混淆——视为已知风险，非阻断项。
- **英文可用性**：Catseye 作为独立词，检索结果均为词典释义或日用词条（猫眼石、道路反光片 cat's eye reflector 等），未发现同名翻译类竞品。

## 关于猫眼星云（NGC 6543）

- **发现**：1786 年 2 月 15 日由威廉·赫歇尔（William Herschel）发现，位于天龙座（Draco）。
- **天文史意义**：1864 年威廉·哈金斯（William Huggins）对其光谱做了首次分析，证明这类"行星状星云"是弥漫气体而非未分辨的恒星集合——这是第一个被光谱证实为气体本质的行星状星云，在天文史上有奠基性意义。
- **距离**：尚无定论，不同来源给出约 3,000～5,300 光年不等；欧空局盖亚（Gaia）任务的测量约为 4,400 光年。
- **年龄与结构**：是一颗年轻的行星状星云，形成约 1,000 年；主体直径约 0.4 光年，两侧的对称喷流延伸至约两倍距离。哈勃望远镜拍摄的图像显示出多层同心壳层和复杂的结节、喷流结构，推测源自中心垂死恒星周期性（约每 1,500 年一次）的物质抛射，是已知结构最复杂的行星状星云之一，也是天区中最亮的行星状星云之一。
- **命名由来**：因其形似猫的瞳孔/眼睛而得名，是"猫眼翻译 / Catseye"这个品牌意象的直接天文出处。

## Open Follow-ups

- 中国商标网 / 美国 USPTO 商标检索尚未核实，正式启用前需要确认
- 域名（catseye.xxx 等）与主流应用商店（Chrome Web Store、App Store）主体名可用性需核实
- Logo / 吉祥物设计（可结合皮皮猫的真实形象 + 猫眼星云的配色）
- 备选 **猫爪翻译 / Catspaw** 保留作为交互动效（如点击翻译时的爪印动画）或未来子品牌的候选素材
