# ADR-084：跳到阅读位置后，句子高亮保留到用户操作

修订 ADR-082 中「提示或 pin 的跳转只滚动并闪烁目标句子」的「闪烁」部分。其他规则不变：仍滚到视口中部，侧边栏关闭时不自动打开，找不到句子时仍按原比例滚动、不高亮并提示。

## Decision

跳到阅读位置后，目标句子用 ADR-025 的**当前句高亮**标出，不再闪 2 秒后消失：

1. 高亮一直保留，直到用户在主窗口里点击或按键（`click` / `keydown`），与整句翻译后的原句高亮相同；滚动不清除。
2. 它就是当前句高亮本身，不另起一种：同一时间页面上只有一句当前句，之后查词触发的整句翻译会替换它，反之亦然。颜色沿用 ADR-054 的暖黄。
3. 关闭学习模式、SPA 切页和失效脚本退场时，与其他当前句高亮一样清除。

## 取舍

Owner 在 HomeLab 实测（2026-11-14）：跳转后句子只闪 2 秒，用户的眼睛还没在新位置找到它，高亮就没了。ADR-025 已经为整句翻译踩过同样的坑——固定计时器总在用户需要时到期，最后定为「用户真的操作了才清除」。跳转是同一个问题，直接复用那条规则和那套实现。

代价：如果用户跳转后只是读、不点也不按键，高亮会一直在。这与整句翻译后的行为一致，用户已经习惯。
