# ADR-082：修订阅读位置与钉住句子的边界

修订 ADR-081 的 Decision 1–7。原 ADR 保留作为历史；本决定只替换下列规则，其他规则继续有效。用户希望整页版与章节版分别记录，跳转不强制打开侧边栏，并避免无法定位的句子覆盖有效位置。

## Decision

### 书的边界

Standard Ebooks 的整页版是一本文本；同一本作品的章节版是另一本，所有章节归在一起。两者分别保存阅读位置和钉住的句子，不互相显示或同步。章节版的侧边栏列出所有章节的 pin；点击其他章节的 pin 先打开其来源页面，再定位句子。其他站点仍默认以规范化页面地址为书标识。

### 定位和跳转

生成锚点时先在当前正文验证句子能否定位，验证不改变页面显示或滚动。验证失败时不覆盖上一个阅读位置，也不自动用邻近句子替代；用户主动 pin 失败时显示提示。网页后来变化仍可能导致找不到，跳转时按原 ADR 的比例兜底并明确提示。

提示或 pin 的跳转只滚动并闪烁目标句子；侧边栏关闭时不自动打开。整句卡保留不显示给用户的来源书、页面和锚点，导航到其他页面后仍可将旧卡 pin 到来源书；缺少可靠来源的卡不能 pin。pin 更新来源书的阅读位置。

### 保存边界和账号

句子原文规整后以 UTF-8 计最多 1 KB；超限不截断，自动记录跳过并保留原位置，主动 pin 显示提示。功能还需总存储预算，避免耗尽扩展共享配额；预算不足或写入失败时保留已有数据并明确提示，不假报成功。

每次操作记录发生时间，阅读位置以较新的有效操作为准；通过统一写入入口协调各标签页和侧边栏的修改，防止延迟写入覆盖新位置或丢失 pin。账号切换或登出后，待写入和跨页待跳转不得泄露给另一账号；执行前验证账号和目标页面。

## 取舍

整页版和章节版分开避免把两种阅读习惯混为一个位置，但不提供跨版本 pin 或进度。保存前验证减少错误覆盖，但不能保证网页修改后仍能找回。统一写入避免防抖与多标签页操作交错造成数据丢失。
