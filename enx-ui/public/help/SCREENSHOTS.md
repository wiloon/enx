# Help screenshots

The help articles work without screenshots. Each figure reserves space and describes the image to capture. Add screenshots under this directory, then ask for the corresponding figure to be updated with its image path and dimensions.

Use an English Chrome interface. Crop unrelated tabs, account information and personal folder paths. Capture the GitHub release's Assets area rather than the repository header where possible, so a repository rename does not invalidate the image. Capture the store search after the listing becomes Public. PNG is preferred. Avoid stretching images; the article column is at most 768 CSS pixels wide.

| File relative to this directory   | Capture                                                                                                                               |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `install/store-search.png`        | Chrome Web Store search results for the product, highlighting the correct extension.                                                  |
| `install/store-listing.png`       | The extension's listing, with its name and Add to Chrome visible.                                                                     |
| `install/enhanced-protection.png` | The complete Proceed with caution dialog, including Continue to install. Use a fresh Chrome profile with Enhanced protection enabled. |

| `offline/extracted-folder.png`    | The extracted extension folder, with manifest.json visible directly inside it.                                                        |
| `offline/load-unpacked.png`       | chrome://extensions with Developer mode enabled and Load unpacked visible.                                                            |
| `get-started/pin-extension.png`   | The puzzle-piece menu, showing the pin beside the extension.                                                                          |
